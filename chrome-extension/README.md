# ⚡ Lapex Flash — Chrome Extension

**Lapex Flash Chrome Extension** is a standalone, serverless developer tool that opens in your Chrome Side Panel directly next to any active Salesforce tab.

## 🚀 Features
- ⚡ **Zero-Server Required**: Operates completely inside Chrome.
- 🔑 **Automatic Session Detection**: Reads your active `sid` cookie from your open Salesforce tab. No manual login or password required.
- 📜 **Local Storage**: All code scripts and debug logs are saved locally in Chrome storage on your machine.
- 🛡️ **No CORS Restrictions**: Interacts directly with Salesforce APIs.

## 📦 How to Install in Chrome

1. Open Google Chrome and navigate to `chrome://extensions`.
2. Enable **Developer mode** (toggle switch in the top-right corner).
3. Click **Load unpacked** (top-left corner).
4. Select this `chrome-extension` folder:
   `c:\Users\LaxmanPatel\OneDrive - Nebarex DMCC\Desktop\RedLine\chrome-extension`

## 💡 How to Use
1. Open any Salesforce org in Chrome.
2. Click the **Extensions** icon 🧩 in Chrome and open **Lapex Flash**.
3. It will open in the **Chrome Side Panel** and auto-detect your session!
